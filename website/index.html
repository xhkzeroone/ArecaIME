Fcitx5 · Wayland-first · Bamboo core

Gõ tiếng Việt trên Linux, theo đúng nhịp của bạn.

Areca là addon Fcitx5 viết bằng C++20. Mọi phím được xử lý tuần tự, Bamboo lo phần tiếng Việt, còn Areca chọn cách rewrite phù hợp với từng ô nhập liệu.

01 Chỉ dùng PreeditMột đường xử lý nhất quán

State composition nằm trong bộ gõ và bám sát giao thức input method, nhờ đó luồng xử lý thường đơn giản, dễ dự đoán.

Chữ đang soạn được hiển thị dưới dạng preedit; cảm giác nhập và cách app trình bày có thể khác với việc gõ trực tiếp vào văn bản.

02 Nhiều mode theo ứng dụngNgười dùng tự chọn backend

Cho phép đổi chiến lược tương thích khi một ứng dụng hoạt động tốt hơn với Preedit, SurroundingText hoặc cách rewrite khác.

Người dùng cần nhớ mode phù hợp cho từng app; trong cùng một app, vùng soạn thảo, terminal và ô tìm kiếm vẫn có thể hành xử khác nhau.

Đổi lại, lớp tích hợp phải tự theo kịp desktop, compositor, toolkit và nhiều giao thức input khác nhau trên Linux.

A Hướng của ArecaThích ứng theo từng input

Giữ Fcitx5 làm nền tảng, tự động đánh giá từng input context, đồng thời hỗ trợ phím tắt chọn nhanh và gán cố định backend cho từng ứng dụng.

Mặc định vận hành tự động không cần can thiệp; khi cần tương thích đặc thù, người dùng có thể chuyển đổi tức thì giữa Surrounding, Shift+Left, Native và ForwardKey.

Thiết lập Fcitx5

Chọn đúng hướng dẫn cho desktop của bạn.

Areca cần Fcitx5, công cụ cấu hình và cách khởi động phù hợp với phiên desktop. Sau khi thay đổi biến môi trường, hãy đăng xuất rồi đăng nhập lại.

Cài Fcitx5 trước khi cài Areca

# Ubuntu / Debian
sudo apt install fcitx5 fcitx5-config-qt fcitx5-frontend-all

# Arch Linux / CachyOS
sudo pacman -S fcitx5-im

# Fedora
sudo dnf install fcitx5 fcitx5-autostart fcitx5-configtool fcitx5-gtk fcitx5-qt

KDE Plasma Wayland

Chọn Fcitx 5 tại System Settings → Keyboard → Virtual Keyboard. Tạo ~/.config/environment.d/fcitx.conf:

XMODIFIERS=@im=fcitx
GTK_IM_MODULE=fcitx
QT_IM_MODULE=fcitx
SDL_IM_MODULE=fcitx

Cấu hình tương thích này hỗ trợ cả app Wayland, XWayland và GTK/Qt cũ. Không thêm autostart thứ hai.

GNOME Wayland

Tạo ~/.config/environment.d/fcitx.conf:

XMODIFIERS=@im=fcitx
GTK_IM_MODULE=fcitx
QT_IM_MODULE=fcitx
SDL_IM_MODULE=fcitx

Chép org.fcitx.Fcitx5.desktop từ /usr/share/applications vào ~/.config/autostart/.

Dùng đủ module để tương thích cả ứng dụng Wayland, XWayland, GTK, Qt và SDL.

Hyprland

Thêm vào ~/.config/hypr/hyprland.conf:

env = XMODIFIERS,@im=fcitx
env = GTK_IM_MODULE,fcitx
env = QT_IM_MODULE,fcitx
env = SDL_IM_MODULE,fcitx
exec-once = fcitx5 -d

Nếu UWSM/XDG autostart đã chạy Fcitx5 thì bỏ dòng exec-once.

Niri

Thêm vào ~/.config/niri/config.kdl:

environment {
    XMODIFIERS "@im=fcitx"
    GTK_IM_MODULE "fcitx"
    QT_IM_MODULE "fcitx"
    SDL_IM_MODULE "fcitx"
}
spawn-at-startup "fcitx5" "-d"

Không thêm spawn-at-startup nếu phiên systemd đã dùng XDG autostart.

Sway / Wayland WM khác

Đặt trong ~/.config/environment.d/fcitx.conf:

XMODIFIERS=@im=fcitx
GTK_IM_MODULE=fcitx
QT_IM_MODULE=fcitx
SDL_IM_MODULE=fcitx

Thêm exec fcitx5 -d hoặc lệnh khởi động tương đương vào cấu hình compositor.

X11

Thêm vào ~/.xprofile:

export XMODIFIERS=@im=fcitx
export GTK_IM_MODULE=fcitx
export QT_IM_MODULE=fcitx
export SDL_IM_MODULE=fcitx
fcitx5 -d

Bỏ dòng cuối nếu desktop đã tự khởi động Fcitx5.

Cuối cùng mở fcitx5-configtool, bỏ chọn Only Show Current Language, tìm Areca (Bamboo) và thêm vào danh sách. Nếu gặp lỗi, chạy fcitx5-diagnose và kiểm tra máy chỉ có một tiến trình Fcitx5.
